# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :x:                |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or safety hazard within the **AI Traffic Management Platform** (especially regarding failsafe signal actuation, hardware watchdog timeouts, or actuator communication):

1. **Do not create a public issue.**
2. Send a report via email to the project maintainers or open a private security advisory through GitHub.
3. Please include:
   - A description of the issue and potential impact
   - Steps to reproduce or proof-of-concept
   - Any proposed remediation or patch

We will acknowledge receipt within 48 hours and work with you to test and release a security fix.
